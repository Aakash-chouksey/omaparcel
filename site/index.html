How it works

What crosses

One link leaves the machine.

The friend gets a URL and a download. Everything else stays where you put it.

01 / the link

tunnelshare-7kq2.trycloudflare.com/s/8f3a…

128 bits of id

expires 18:40

A capability, not a copy.

The URL carries 128 random bits. Whoever holds it can read the share. Revoke it and the same URL answers 410.

02 / the bytes

your disk their browser

byte ranges, answered locally

Streamed from the disk.

The browser asks for ranges and the daemon answers from the original file. A 5 GB folder costs no storage because no second copy exists.

03 / the door

6 digit code, optional

8 tries, then locked

Every link ends.

Shares carry an expiry. A 4 to 8 digit code can guard the sensitive ones. Eight wrong tries lock the share for ten minutes.

Cloudflare's free plan carries the tunnel. Your disk carries the bytes. A quick tunnel needs no account and no domain.

A named tunnel keeps the same hostname across restarts. It needs a Cloudflare account and a domain you already own, which is the only line that can add cost.

The daemon serves downloads as fast as your upstream allows. Cloudflare's free plan caps a request body at 100 MB, and that limit applies to uploads. Downloads have no enforced cap.

Install

Three commands.

A venv, a config file, and a systemd user unit. No sudo, no network calls except pip.

01

Clone

git clone https://github.com/Aakash-chouksey/tunnelshare.git
02

Install and enable the unit

cd tunnelshare && ./install.sh --enable
03

Share a folder for 24 hours

tsctl share ~/Pictures/Riverside --hours 24 --note "Riverside, October"

Limits

What it will not do.

Work while the laptop sleeps

The bytes live on your machine, so the machine stays awake and online while a friend downloads.

Give a quick tunnel a stable name

A quick tunnel gets a new hostname on every restart. Old links stop working. A named tunnel keeps its name.

Take browser uploads above 100 MB

Cloudflare's free plan caps the request body. The CLI never uploads, and downloads have no such cap.

Serve large media as a public service

Cloudflare's free zone terms want a paid plan for that. Sharing with friends is fine.
