The link is the capability.

A 128-bit id in the URL. Whoever holds it can read the share; revoke it and the same URL answers 410. No public directory, no browse.

Read about access →

Nothing waits in storage.

The browser asks for ranges; the daemon reads them off disk and streams them back. No object store, no second copy, no warehouse to clean up.

See what that saves →

It closes itself.

Every share carries an expiry. Eight wrong codes lock it for ten minutes. Stop the daemon and the link dies with it.

InstallLinux · macOS

Hand it to
your machine.

Pick a folder. Send the link. Keep the file.

Python 3.10+, cloudflared, and a systemd user service for the panel. No sudo for the daemon, no network calls except the tunnel and pip.

Read the install notes →

Alpha software. Shares end when the daemon stops. It is not a CDN and has no SLA.

01 curl -fsSL https://raw.githubusercontent.com/Aakash-chouksey/omatunnel/main/install.sh | bash -s -- --enable
02 tsctl share ~/Pictures/Riverside --hours 24 --note "Riverside, October"

One command installs the daemon, the panel, and the tsctl CLI. Then share any folder; the daemon prints the link.

LimitsStraight answers

A few things
to know.

omatunnel is a small share daemon, not a platform. These are the boundaries, written down.

Does it work while my laptop sleeps?

No. The bytes live on your disk, so the machine has to be awake and online while someone downloads. If the lid closes, the download stops.

Do recipients need an account or an app?

No. The link opens in a normal browser. Downloads use plain HTTP range requests, so they can resume after a dropped connection.

What happens when a link expires?

The daemon stops serving it and the URL answers 410. Start a new share for a new link. Expiry is checked per request, not by a background job.

Is my file uploaded anywhere?

No. Cloudflare carries the request and the response, but the bytes are read from your disk on demand. omatunnel has no object storage and keeps no copy.

Can I send more than 200 GB?

Yes. There is no transfer cap. The one hard ceiling is Cloudflare’s 100 MB request body limit, which applies to uploads into the panel; downloads have no enforced cap.

Can I lock a link?

Yes: --pin 4821. Codes are 4–8 digits, stored as PBKDF2-HMAC-SHA256 with 210k rounds. Eight wrong tries lock the share for ten minutes.

Can I use my own domain?

A quick tunnel gets a random trycloudflare.com hostname that changes on every restart. A named tunnel needs a Cloudflare account and a domain you already own; that is the only path that can add cost.

What does it cost?

Nothing. The Cloudflare free plan carries the tunnel, no account is needed for a quick tunnel, and your disk carries the bytes. The bills are compared above.

What will it not do?

It will not keep files online while your machine is off, serve as a public CDN, or survive a lost laptop. It will not invite a recipient into a repo or an app; it hands over files.
